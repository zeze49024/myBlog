# UI 第一版 · 把想法，写成现实

设计日期：2026-10-22。供本地评审，尚未部署 `zeze49024.com`。

## 方向

以编辑式排版、大留白与小型产品场景展示为主线。黑白灰建立秩序，电光蓝引导主要操作，少量紫色与绿色区分项目类型。用户提供的头像是唯一人物视觉，不使用替代人像。

首屏以“把想法，写成现实。”建立记忆点，右侧倾斜个人卡片与浮动代码标签连接个人身份和编程项目。下一屏进入项目展示，再自然过渡到开发记录、个人介绍和 GitHub 引导。

页面文案是根据需求拟定的第一版，可在评审后修改。没有展示职业、联系方式、虚构贡献量、下载量或用户评价。

## 页面结构

1. 顶部：个人标记、单页锚点导航、深浅色切换，手机折叠菜单。
2. 首屏：主标题、介绍、项目与 GitHub 按钮、头像个人卡片。
3. 兴趣栏：桌面、移动、Web 与游戏模组。
4. 项目：5 张卡片涵盖 6 个公开仓库，支持类型筛选。待办发布仓库合并为补充链接。
5. 博客：一篇设计草稿、两篇内容示例，点击在原生 dialog 中阅读。
6. 关于：济南所在地、北京时间、兴趣标签、SVG 社交按钮。
7. 尾部：GitHub 行动入口、版权行、回到顶部。

## 视觉参数

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 | `#F8F9FB` | `#111318` |
| 卡片背景 | `#FFFFFF` | `#1A1D25` |
| 主文字 | `#20232B` | `#EDF0F7` |
| 次文字 | `#747B89` | `#989EAF` |
| 边线 | `#E5E7EC` | `#2B2F3A` |
| 主强调 | `#255DE9` | `#7B9EFF` |

- 主按钮保持实蓝底白字；辅助按钮白底或深色卡片底，使用细边线。
- 主内容最大宽度 1200–1240px，电脑边距 32–40px，手机边距 23px。
- 卡片圆角 11–16px，按钮 8px，标签 4–6px；阴影低对比，仅辅助建立层次。
- 字体优先使用本机 Inter / Segoe UI / 苹方 / 微软雅黑，不请求外部字体服务。
- 首屏标题 51–72px，正文使用中文系统字体；英文小字仅作视觉辅助，主要内容均为简体中文。
- 图标使用 Lucide，品牌 Logo 使用 Simple Icons 的 GitHub 与 Bilibili SVG。

## 响应式

手机小于 768px：首屏上下排列、项目与博客单列、折叠导航。768–1023px 项目两列，1024px 起三列。1440px 为宽屏检查点；390px 和 320px 为手机检查点。

## 交互与动效

- 浅色为默认模式；手动切换后保存在 localStorage，刷新后保留。不可用时依然可在当前页切换。
- 固定导航、平滑锚点、当前章节高亮、页面顶部滚动进度。
- 首屏分层入场、标题下划线绘制、悬浮标签漂浮、装饰星缓慢旋转。
- 鼠标在首屏卡片附近移动时产生轻微 3D 倾斜；触屏不启用此效果。
- 项目与文章滚动入场；卡片悬浮上移；项目箭头与按钮有反馈。
- 项目筛选真实隐藏其他卡片，按钮更新按下状态与数量。
- 博客使用原生模态 dialog，支持键盘、Esc、关闭按钮及点击遮罩关闭，关闭后回到原触发按钮。
- GitHub / B 站按钮打开真实主页；虚线加号显示更多渠道的提示，不指向空链接。
- 遵循 `prefers-reduced-motion`，关闭动画与平滑滚动。键盘焦点可见，提供跳过导航链接。
