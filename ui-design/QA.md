## 说明与限制

- `preview.html` 由已通过构建的 CSS 与 JS 内联生成，头像为内嵌 data URL，不依赖 CDN。内置浏览器安全策略拒绝 `file://`，未在内置浏览器中实际双击验证离线文件；交互验证基于同一源码的 HTTP 预览。
- 卡片视觉为设计示意；项目介绍使用核实的信息。未发布博客文章，也没有文章管理、评论或登录后台。
- 减少动态效果媒体查询、键盘焦点样式与原生 dialog 已实现；未进行专门的读屏器或全量无障碍审计。
- GitHub 地址已经与公开仓库清单比对。未对每个外链进行跨站点击、下载或产品验收。
- 尚未部署到服务器，未配置 DNS、HTTPS、备案或更改现有站点。

## 本地复核

直接打开 `preview.html`，或在根目录执行 `npm ci` 与 `npm run dev`。
修改源码后执行 `npm run build`，重新生成独立预览。截图为第一版评审快照，不会随源码自动更新。
